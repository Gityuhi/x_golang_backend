# X-Clone API Backend (Go)

このリポジトリは、Go言語とクリーンアーキテクチャで実装されたXクローンAPIのソースコードです。

## 概要

プログラミングスクール「HappinessChain」の課題として、バックエンド開発における実践的な設計・実装スキル習得を目的に開発しています。


## アーキテクチャの実装

### 🏗️ クリーンアーキテクチャの実装

- **ドメイン層**: ビジネスロジックの中核となるモデル、リポジトリインターフェース、サービスインターフェースを定義
- **ユースケース層**: アプリケーション固有のビジネスルールを実装
- **インターフェース層**: HTTPハンドラーとルーターで外部との接続を管理
- **インフラストラクチャ層**: PostgreSQL、Redis、メール送信などの外部依存関係を実装

### 依存関係の方向性

```
Interface → UseCase → Domain ← Infrastructure
```

- 上位層は下位層のみに依存
- 依存性はインターフェースを介して注入
- Domain 層は他の層に依存しない


## 実装済み機能

- **ユーザー認証**
  - ユーザー新規登録 (SignUp)
  - メールに送信するリンクよりアカウント有効化 (User Activation)
  - ログイン (Login) / JWTによる認証

## 使用技術スタック

### バックエンド

- **言語:** Go 1.25.0
- **フレームワーク:** Gin
- **認証:** JWT
- **パスワードハッシュ:** bcrypt

### データベース・キャッシュ

- **メイン DB:** PostgreSQL 14
- **キャッシュ:** Redis 7
- **ORM/クエリビルダー:** SQLC 
- **マイグレーション:** golang-migrate

### インフラ・開発環境

- **コンテナ:** Docker, Docker Compose
- **マルチステージビルド:** Development/Builder/Production
- **ホットリロード:** Air
- **メール送信:** SMTP (開発時は MailHog)

### アーキテクチャパターン

- **設計:** クリーンアーキテクチャ
- **依存性注入:** インターフェースベース設計
- **レイヤー分離:** Domain/UseCase/Interface/Infrastructure

## 環境構築

### 前提条件

- Docker & Docker Compose
- Git

### セットアップ手順

1. **リポジトリをクローン**

   ```bash
   git clone https://github.com/Gityuhi/x_golang_backend
   cd x_golang_backend
   ```

2. **環境変数の設定**
   `.env.example` ファイルをコピーして `.env` ファイルを作成し、必要に応じて値を調整してください。

   ```bash
   cp .env.example .env
   ```

3. **開発環境の起動**

   ```bash
   # 開発環境（ホットリロード付き）
   docker-compose -f compose.dev.yaml up -d --build
   ```

4. **本番環境の起動**
   ```bash
   # 本番環境
   docker-compose up -d --build
   ```

### 開発環境の特徴

- **ホットリロード**: コード変更時に自動でアプリケーションが再起動
- **MailHog**: メール送信のテスト用（http://localhost:8025）
- **ポート分離**: 開発環境は 8081、本番環境は 8080 で起動
